# Taste-tinker

**Taste-tinker** is a full-stack web application project consisting of separate **frontend** and **backend** components, designed to provide users with an interactive experience around taste-related data or features (e.g., recipes, preferences, or culinary exploration). The app follows a traditional client-server architecture with the frontend handling UI/UX and the backend providing data and API logic.

## Tech Stack

* **Frontend:** React framework, JavaScript, HTML, CSS
* **Backend:** Python or Node.js with REST API
* **Database:** MongoDB
* **Containerization:** Docker

## Getting Started

### Prerequisites

Make sure you have the following installed:

* Node.js & npm/Yarn (if frontend is JS)
* Python & pip (if backend is Python)
* Docker (optional, for containerization)
* Database (e.g., PostgreSQL, MongoDB — update based on your setup)

### Installation

1. **Clone the repo**

   ```bash
   git clone https://github.com/maplepolis/Taste-tinker.git
   cd Taste-tinker
   ```

2. **Backend Setup**

   ```bash
   cd backend
   # install dependencies, e.g.:
   npm install       # or pip install -r requirements.txt
   ```

3. **Frontend Setup**

   ```bash
   cd frontend
   npm install       # or yarn install
   ```

4. **Run locally**

   ```bash
   # Start backend
   cd backend
   npm start         # or python app.py

   # Start frontend
   cd frontend
   npm run dev       # or equivalent
   ```
